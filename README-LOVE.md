## 🛠️ **Customization**

### **Colors**
Edit CSS variables in any HTML file:
```css
:root {
    --rose-pink: #F8BBD0;
    --blush-pink: #F48FB1;
    /* Add your custom colors */
}
```

### **Messages**
Update emotion messages in `experience.html`:
```javascript
const emotionMessages = [
    "Your custom message here! 💕",
    "Add more emotional text",
    "Personalize the experience"
];
```

### **Photos**
Replace photos in the `/photos` folder:
- Supported formats: `.jpg`, `.jpeg`
- Naming: `1.jpeg`, `2.jpeg`, etc.
- Auto-sorted numerically
